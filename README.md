# Programming for AI - Assignment 3

This repository contains my completed Programming for AI Assignment 3.

## How to Run

Open `Assignment3_Programming_for_AI.ipynb` in Jupyter Notebook or VS Code and run all cells from top to bottom. The required data files are stored in the `data` folder. The notebook generates `dashboard.png`, `dashboard.pdf`, and `wave.gif` inside the `outputs` folder.

## Difficult Part

The most difficult part was cleaning and analysing the messy datasets while correctly handling missing values, invalid readings, mixed date formats, and NumPy broadcasting. I also found creating the multi-panel dashboard and animation challenging because several plots and data sources had to work together correctly.
